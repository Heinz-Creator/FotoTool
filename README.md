# FotoTool 1.0

**FotoTool** ist ein lokales Windows-Programm zum automatischen Sortieren, Analysieren und Bereinigen von Fotosammlungen.
Alle Funktionen laufen **ohne Cloud** direkt auf deinem eigenen PC.

---

## ✨ Funktionen

* Fotos automatisch nach **Jahr und Monat** sortieren
* Erkennung von **WhatsApp-Bildern** und **Screenshots**
* **Event-Sortierung nach Zeit und Ort** (GPS + Datum)
* Analyse von **unsortierten Dateien** mit Zielvorschlägen
* Finden und Löschen von **Duplikaten**
* Schreiben von **Schlagwörtern in Bild-Metadaten**
* Vollständig **offline & lokal**

---

## 🖥️ Systemanforderungen

* Windows 10 oder Windows 11
* Keine Installation zusätzlicher Software nötig
* Keine Internetverbindung erforderlich (außer optional für Ortsnamen über GPS)

## 🚀 Schnellstart

1. Programm starten
2. Import-Ordner auswählen (z. B. Handy-Fotos)
3. Ziel-Archiv wählen
4. **Sortieren starten**

Fertig.
FotoTool organisiert deine Bilder automatisch.

---

## 🔒 Datenschutz

FotoTool arbeitet **komplett lokal**:

* Keine Cloud
* Kein Upload
* Keine Datensammlung
* Keine Tracking-Dienste

Deine Fotos bleiben auf deinem Computer.
