# FotoTool

Lokales Windows-Programm zur automatischen Sortierung von Fotos und Videos
nach Datum, WhatsApp, Screenshots oder Events.

## Funktionen

- Sortieren nach EXIF-Datum oder Dateidatum
- Event-Erkennung nach Zeit + GPS
- Analyse von unsortierten Dateien
- Duplikate finden mit Czkawka
- Lokale Verarbeitung ohne Cloud

## Installation

1. Setup herunterladen
2. Setup ausführen
3. FotoTool starten

## Lizenz

Private, nicht-kommerzielle Nutzung.
Externe Komponenten unter ihren jeweiligen Open-Source-Lizenzen.
